# 流式输出功能

## 概述

评估过程现在支持实时进度显示，用户可以观看整个评估过程，而不是黑屏等待 2 分钟。

**版本**: v1.5 (流式输出优化版)
**发布日期**: 2026-03-16

## 功能特性

- ✅ 实时进度条显示（0-100%）
- ✅ 已完成模块立即显示
- ✅ 平滑的淡入动画
- ✅ 友好的进度提示
- ✅ 自动重试机制
- ✅ 3分钟超时保护

## 进度节点

| 进度 | 步骤 | 提示信息 |
|-----|------|---------|
| 0% | 准备 | 准备评估... |
| 5% | 解析文章 | 正在解析文章... |
| 10% | 解析完成 | ✅ 文章解析完成 |
| 15% | GICS 分类 | GICS 行业分类中... (正在分析 163 个行业) |
| 30% | 分类完成 | ✅ GICS 分类完成 |
| 35% | AI 评估 | AI 评估分析中... (这是最大头的步骤，请稍候) |
| 50% | AI 评估中 | AI 评估分析中... (已完成一半) |
| 80% | 评估完成 | ✅ AI 评估完成 |
| 85% | 战略建议 | 正在生成战略建议... |
| 100% | 全部完成 | 🎉 评估完成 |

## 使用方式

### 方式1: URL 评估

1. 在评估表单中选择"URL链接"标签
2. 粘贴文章 URL（支持微信公众号、知乎、豆瓣等）
3. 点击"🚀 开始智能评估"
4. 观察顶部进度条实时更新
5. 各步骤完成后自动显示结果模块

### 方式2: 内容评估

1. 在评估表单中选择"文章内容"标签
2. 粘贴或输入文章内容（50-10000字）
3. 点击"🚀 开始智能评估"
4. 观察实时进度更新
5. 查看评估结果

## 错误处理

### 连接中断
- **现象**: 进度条显示"❌ 连接中断"
- **解决**: 点击"🔄 重新评估"按钮重试

### 评估超时
- **现象**: 进度条显示"❌ 评估超时"
- **原因**: 评估时间超过 3 分钟
- **解决**: 稍后重试或联系管理员

### 解析失败
- **现象**: 进度条显示"❌ 解析失败"
- **原因**: URL 无效或文章无法访问
- **解决**: 检查 URL 或尝试直接输入内容

## 技术实现

### 后端
- **技术**: Server-Sent Events (SSE)
- **路由**: `/api/evaluate-stream`
- **通信**: 单向实时推送
- **超时**: 180 秒（3 分钟）

### 前端
- **技术**: EventSource API
- **进度条**: 顶部固定，sticky 定位
- **动画**: CSS 渐变 + 过渡效果
- **重试**: JavaScript 自动重连

## 性能指标

- **进度更新延迟**: < 100ms
- **前端渲染流畅度**: 60fps
- **内存占用增加**: < 10MB per connection
- **支持并发**: 最多 10 个同时连接
