# 三阶段评估架构 - 完整设计文档

## 系统概述

基于您的思路，我设计并实现了一个三阶段的智能评估系统：

1. **阶段1：产业研究报告生成** - 基于GICS行业 + 基准数据 + 网络搜索
2. **阶段2：行业判断基准生成** - 基于研究报告 + 基线数据
3. **阶段3：文章评估** - 对比文章内容与判断基准

## 使用方式

### 方式1：完整三阶段评估

```javascript
const orchestrator = require('./src/services/evaluationOrchestrator');

const article = {
  title: '文章标题',
  content: '文章内容...',
  source: '来源',
  url: '链接'
};

const result = await orchestrator.evaluate(article, '应用软件', {
  useCache: true,       // 使用缓存（推荐）
  enableSearch: false   // 是否启用网络搜索
});

console.log(result.evaluation);
```

### 方式2：快速评估（使用已有基准）

```javascript
// 前提：已经生成过该行业的基准
const result = await orchestrator.quickEvaluate(article, '应用软件');
```

### 方式3：批量评估

```javascript
const articles = [article1, article2, article3];

const results = await orchestrator.batchEvaluate(articles, '应用软件', {
  useCache: true
});

// 只在第一篇时生成报告和基准，后续复用
```

## 行业关键词映射

为了自动识别文章所属行业，可以建立关键词映射：

```javascript
const industryKeywords = {
  '应用软件': ['SaaS', '应用软件', '企业管理软件', 'CRM', 'ERP'],
  '系统软件': ['操作系统', '数据库', '中间件', '系统软件'],
  '互联网服务': ['互联网', '电商平台', '在线服务'],
  // ... 更多映射
};

function detectIndustry(articleContent) {
  for (const [industry, keywords] of Object.entries(industryKeywords)) {
    for (const keyword of keywords) {
      if (articleContent.includes(keyword)) {
        return industry;
      }
    }
  }
  return null; // 无法自动识别
}
```

## 性能优化

| 操作 | 首次耗时 | 缓存后耗时 |
|------|---------|-----------|
| 生成产业研究报告 | ~2分钟 | ~0秒 |
| 生成判断基准 | ~1分钟 | ~0秒 |
| 评估单篇文章 | ~30秒 | ~30秒 |
| 批量评估N篇 | ~3分钟+30N秒 | ~30N秒 |

**建议：**
- 对于高频行业（如SaaS、人工智能），预先生成报告和基准
- 定期更新缓存（报告7天，基准30天）
- 批量评估时复用同一基准

## 总结

这个三阶段评估系统：

1. **深度优先**：先深入理解行业，再进行评估
2. **基准驱动**：有明确的判断标准，不是主观臆断
3. **量化溯源**：所有判断都有数据支撑和来源标注
4. **可扩展**：易于添加新行业、新维度
5. **可复用**：报告和基准可以缓存，提高效率
