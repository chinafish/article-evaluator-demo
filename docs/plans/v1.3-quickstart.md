### 方式3：使用代码

```javascript
const CognitiveOrchestrator = require('./src/services/CognitiveOrchestrator');

async function evaluateArticle() {
  const article = {
    title: '文章标题',
    content: '文章内容',
    source: '36氪',
    url: 'https://...'
  };

  const result = await CognitiveOrchestrator.evaluate(article);

  // 查看评估结果
  console.log('评估版本:', result.meta.version);
  console.log('基准类型:', result.meta.benchmark_type);

  // BLOCK 0: 总体判断
  if (result.blocks && result.blocks.BLOCK_0) {
    console.log('总体判断:', result.blocks.BLOCK_0.content);
  }

  // BLOCK 1: 核查详情
  if (result.blocks && result.blocks.BLOCK_1) {
    console.log('核查详情:', result.blocks.BLOCK_1.content);
  }

  // BLOCK 2: 认知盲区
  if (result.blocks && result.blocks.BLOCK_2) {
    console.log('认知盲区:', result.blocks.BLOCK_2.content);
  }

  // BLOCK 3: 评估依据
  if (result.blocks && result.blocks.BLOCK_3) {
    console.log('评估依据:', result.blocks.BLOCK_3.content);
  }
}

evaluateArticle();
```

## 🔧 常见问题

### Q1: 如何切换回v1.2？

访问 `http://localhost:8000/index.v1.2.html`

### Q2: 如何添加新的行业基准？

1. 进入管理后台：`http://localhost:3000/admin`
2. 选择行业
3. 点击"生成行业认知基准"
4. 等待2-3分钟

### Q3: 评估失败怎么办？

检查：
1. 文章内容是否完整（至少500字）
2. 网络连接是否正常
3. API密钥是否配置

查看日志：
```bash
tail -f logs/evaluator.log
```

### Q4: 如何提高评估速度？

1. 使用本地缓存（行业基准）
2. 减少文章长度（截取前2000字）
3. 调整AI模型参数（temperature, maxTokens）
