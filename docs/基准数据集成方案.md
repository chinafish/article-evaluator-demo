# 基准数据集成方案

## 数据来源

**何志毅教授企业图谱数据** - 清华产业研究院发布

### 数据规模
- **163个行业分类**（GICS四级分类）
- 每个行业包含：
  - 全球Top 10企业（市值/营收/利润/净资产/研发费用/营收利润率/ROE/研发强度）
  - 中国Top 4企业（相同8项指标）

## 集成架构

```
文章输入
   ↓
文章解析 (articleParser.js)
   ↓
路由判断 (coordinator.js)
   ↓
SaaS分析器 (saasAnalyzer.js)
   ↓
┌─────────────────────────────────────┐
│  基准数据注入 (benchmarkData.js)    │
│  - 根据文章提取的行业关键词         │
│  - 查询何志毅企业图谱数据库         │
│  - 生成行业基准对比数据             │
└─────────────────────────────────────┘
   ↓

   - 注入行业基准数据
   - AI进行量化对比分析
   ↓

```

## 使用流程

### 1. 初始化基准数据服务

```javascript
const benchmarkData = require('./services/benchmarkData');

// 在系统启动时预加载数据
await benchmarkData.loadData();
```

### 2. 在SaaS分析器中集成

```javascript
// src/services/saasAnalyzer.js
const benchmarkData = require('./benchmarkData');

async analyze(article, routeInfo) {
  // 1. 原有分析逻辑
  const prompt = this.buildPrompt(article, routeInfo);

  // 2. 🆕 注入基准数据
  const industryKeywords = this.extractIndustryKeywords(article.content);
  const benchmarkContext = await this.buildBenchmarkContext(industryKeywords);

  // 3. 将基准数据注入到Prompt中
  prompt.system += '\n\n' + benchmarkContext;

  // 4. 调用AI分析
  const response = await this.callAI(prompt);
  // ...
}
```

### 3. 提取行业关键词

```javascript
extractIndustryKeywords(content) {
  // 行业关键词映射表
  const industryMap = {
    '软件': '软件服务',
    'SaaS': '软件服务',
    '云计算': 'IT服务',
    'AI': '人工智能',
    '人工智能': '人工智能',
    // ... 更多映射
  };

  const keywords = [];
  for (const [keyword, industry] of Object.entries(industryMap)) {
    if (content.includes(keyword)) {
      keywords.push(industry);
    }
  }

  return keywords;
}
```

### 4. 构建基准数据上下文

```javascript
async buildBenchmarkContext(keywords) {
  let context = '# 行业基准数据（何志毅教授评估指标体系）\n\n';

  for (const keyword of keywords) {
    const benchmarkText = await benchmarkData.formatForPrompt(keyword);
    if (benchmarkText) {
      context += benchmarkText + '\n\n';
    }
  }

  if (!context.includes('行业基准数据')) {
    context += '暂无相关行业基准数据。\n';
  }

  return context;
}
```

## 注意事项

1. **数据编码问题**：CSV文件使用UTF-8编码，需要正确处理中文
2. **数据格式**：指标格式为 "数值/数值/..."，需要正确解析
3. **缺失值处理**：部分指标值为 "nan"，需要过滤
4. **性能优化**：数据较大（163行业），建议系统启动时预加载
5. **关键词映射**：需要建立文章关键词 → GICS分类的映射表

## 扩展方向

1. **动态关键词提取**：使用NLP自动识别文章中的行业关键词
2. **多维度基准**：除了行业维度，还可以增加企业规模、发展阶段等维度
3. **时间序列基准**：如果有多年度数据，可以提供趋势对比
4. **自定义基准**：允许用户上传自己的基准数据
