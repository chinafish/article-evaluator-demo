# 文章评估智能体 — 业务数据架构

## 用户输入

用户粘贴一篇文章 URL

## 第一步：文章内容提取

- **工具**：Axios + Readability（快速）/ Puppeteer（反爬降级）
- **输出**：文章标题 + 正文（最多10000字）+ 来源网站

## 第二步：识别文章属于哪个行业

- **方法**：AI 分析文章标题和前2000字，匹配 GICS 四级行业分类
- **覆盖范围**：163 个行业
- **输出**：例如「应用软件」（置信度 0.95）

## 第三步：准备行业知识底座（核心数据融合）

### 数据源 A：何志毅企业图谱（清华）

- 覆盖 163 个 GICS4 行业
- 每个行业包含：全球冠军企业 + 全球Top10 + 中国Top4
- 每家企业有：市值/营收/利润/利润率/ROE/研发强度等

### 数据源 B：行业研究报告（管理后台预生成）

- 管理后台触发，AI 花约3分钟生成一份深度报告
- 已缓存4个行业：应用软件/新能源汽车/汽车零部件/电气设备
- 报告包含 9 大维度：
  1. 行业概述：定义/市场规模/增速/发展阶段/全球定位
  2. 产业链：上游/中游/下游关键环节
  3. 竞争格局：全球冠军 + 中国代表企业 + 竞争模式
  4. 发展趋势
  5. 关键挑战
  6. 机会
  7. 成功因素
  8. 投资洞察
  9. 战略建议
- 加工产出：评估维度/评分标准/对比基准/盲区检查清单

### 融合加工

从上述两个数据源中提取关键信息，注入评估 Prompt：

- 行业发展阶段 + 全球定位 + 市场规模
- 关键数据表格（市场规模、增速、头部企业财务数据）
- 竞争格局描述（全球龙头、中国企业代表、竞争模式）
- 产业链上下游
- 成功关键因素 + 行业常见误区

## 第四步：AI 评估分析

- **角色**：服务于企业高管的「文章可信度分析师」
- **视角**：为 SaaS 成熟期企业评估，关注竞争格局、客户增长
- **AI 收到的信息**：用户背景（行业/阶段/关注点）+ 行业知识底座（上述融合数据）+ 待评估文章全文

AI 做的事：

- 文章中可核查的数据声明 → 逐条比对行业数据
- 文章中的逻辑推论 → 检验因果是否成立
- 文章隐含的错误前提 → 对照行业常识
- 文章未提及的重要内容 → 对照行业知识

## 第五步：结构化输出 Block 0/1/2/3

### Block 0 总体判断（首屏5秒）

- 4个内容标签（文章主题分类）
- 判定结论：可以采信 / 基本可信 / 谨慎采信 / 不建议采信
- 一句话总结
- 4张摘要卡片：事实核查结果 / 逻辑核查结果 / 盲点数 / 时效性
- 判断方法说明

### Block 1 核查详情

- 数据核查清单：文章说 vs 实际情况 vs 来源 vs 判定
- 逻辑核查清单：论点验证 + 隐含错误前提纠正

### Block 2 认知盲区

- 文章未提及但对该行业决策者重要的信息

### Block 3 评估依据（可折叠）

- 评估视角（用户画像说明）
- 行业全景：定义/阶段/全球定位/市场规模/关键数据/竞争格局/产业链
- 行业研究报告（可跳转完整报告）
- 认知基准说明

## 数据来源总结

| 数据来源 | 内容 | 用途 |
|---------|------|------|
| 何志毅企业图谱 (清华) | 163个行业的企业财务数据 | 核查文章数据声明的真实性 |
| AI 生成的行业研究报告 | 9大维度的深度行业分析 | 提供行业全景、产业链、竞争格局等背景知识 |
| 用户输入的文章 | URL 或粘贴的全文 | 评估对象 |
| AI 模型 (Qwen/Kimi) | 分类 + 评估 + 报告生成 | 驱动所有智能分析环节 |
